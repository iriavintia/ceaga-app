# App socias CEAGA

Prototipo web de la app para empresas socias de CEAGA, con su backoffice.

- `index.html`: la app completa (HTML estático, React desde CDN). No necesita compilación.
- Despliegue: Vercel, como sitio estático (sin framework, sin build).

Los datos son de ejemplo y se reinician al recargar la página.
